# NSYSU HUD

中山大學生活用的 iPhone 主畫面「指揮中心」小工具（Scriptable）。
依時段自動切換內容：課表與下一堂教室、考試／截止倒數、天氣與帶傘提醒、YouBike、台股觀察清單、校內公告、美股大事。
公告監看、YouBike、課程異動、EMI 中心活動預約（English Table 等）與美股提醒由 GitHub Actions 在雲端定時處理，有新東西就用 ntfy 推播到手機和 Apple Watch。

---

## 安裝

1. 在 App Store 安裝 **Scriptable**（免費）。
2. 打開 Scriptable，右上角「＋」新增腳本，把 [`install/HUD-Loader.js`](install/HUD-Loader.js) 的內容**整段貼上**，左上角把腳本名稱改成 `NSYSU HUD`。
3. 點右下角 ▶︎ **執行一次**。第一次會跳出「取用行事曆」的權限（要排帶傘提醒時會再問「傳送通知」），都按**允許**。執行後會打開完整儀表板，代表安裝成功。
4. 回到主畫面，長按空白處 →左上角「＋」→ 找到 **Scriptable** → 選**大尺寸**（中、小尺寸也可以，是簡化版）→ 加入。
5. 長按剛加入的小工具 →「編輯小工具」→ Script 選 **NSYSU HUD**，「When Interacting」維持 **Run Script**。

之後主程式會自己每天檢查一次更新；沒有網路時會用上次下載的版本，不會壞掉。

### 第一次在 GitHub 上要做的設定（只做一次）

1. **Pages**：repo 的 Settings → Pages → Build and deployment 的 Source 選 **GitHub Actions**。
2. **推播主題**：Settings → Secrets and variables → Actions → New repository secret，名稱 `NTFY_TOPIC`，值填你的 ntfy 主題名稱（另外給，不要寫進任何檔案）。
3. **啟用 Actions**：Actions 分頁如果出現提示，按啟用。可以先到 Actions → `data` → Run workflow 手動跑一次，建立公告的基準資料（第一次不會推播）。

## 推播（ntfy）

1. 在 App Store 安裝 **ntfy**。
2. 打開 ntfy →「＋」訂閱主題，伺服器用預設的 `ntfy.sh`，主題名稱填上面 `NTFY_TOPIC` 那個（主題名稱另外給，不寫在 README）。
3. 到 iPhone 設定 → 通知 → ntfy 允許通知；Apple Watch 會自動跟著 iPhone 顯示。

會收到的推播：

| 推播 | 什麼時候 | 例子 |
|---|---|---|
| 📢 中山公告 | 台北 07:00–23:30，每 30 分鐘檢查；同一輪多則合併成一則 | 「中山公告 3 則」，點開到第一則原文 |
| ⚠️ 課程異動 | 每天 08:00 比對 8 門課的教室、時間、異動欄位 | 「普物教室改到 工EC 2011」 |
| 📈 今晚美股大事 | 每天晚上，今晚到明早 06:00 有事件時 | 「今晚 21:30 美國 CPI（10 月）」「凌晨 2:00 聯準會利率決議」 |
| ⏰ 開放預約提醒 | EMI 中心預約系統（EEARS）每次開放預約的 **5 分鐘前**，準時送到 | 「12:00 開放預約：English Club、Job Talk」，列出那次開放的場次，點開到預約頁 |
| 🆕 新增場次 | EEARS 加開場次時（台北 07:00–23:30，每 10 分鐘檢查） | 「EEARS 新增場次：Job Talk」＋什麼時候開放 |

EEARS 各活動什麼時候開放，是預約系統自己公告的規則（不用登入就讀得到），目前是：English Table 前一天 12:00、Job Talk 7 天前 12:00、English Club 前一個週三 12:00，都在活動開始前 2 小時截止。跟課表衝堂的場次不提醒；剛下課就開始的場次會加註「XX 16:00 下課，注意別遲到」。

另外小工具自己會在手機上排一則**隔天 07:30 的帶傘提醒**（只在會下雨時，固定只有一則，不會重複）。

## 每個模式長怎樣

小工具依台北時間、星期、行事曆和學期狀態自動切換。右上角是現在氣溫，右下角小字是更新時間；資料過期時會變灰並標出是幾點的資料。

| 模式 | 什麼時候 | 內容 |
|---|---|---|
| 🌅 早晨 | 平日 06:00–09:10 | 今天天氣（氣溫、最可能下雨的時段、要不要帶傘、曬太陽好時段）、今日課表、第一堂還有多久、最近 3 個倒數 |
| 📘 上課日 | 有課的日子 09:10 起，到當天最後一堂下課 | 現在這堂（課名、教室、還有幾分鐘下課，下面有一條上課進度條）、下一堂（課名、教室、幾點）、台股精簡列、帶傘／曬太陽、今天可以去的 EEARS 活動、倒數 |
| ☕ 午後 | 13:30–18:00 沒課或下課後 | 台股收盤摘要（台積電、加權指數、每個題材平均與漲最多／跌最多）、倒數、晚上會不會下雨、過去 24 小時新公告數 |
| 🌙 晚間 | 每天 18:00–24:00 | 7 天內的考試／截止、明天第一堂（幾點、教室；放假或週末會說明）、明天天氣與要不要帶傘、明天可以去的 EEARS 活動和 24 小時內開放預約的場次、今天新公告標題（標上來源）、今晚的美股大事（沒有就顯示下一個） |
| 💤 深夜 | 每天 00:00–06:00 | 極簡、大字：第一堂、最近的考試倒數 |
| ☀️ 假日 | 週六日、放假日、寒假的 06:00–18:00 | 倒數、天氣、下週一（下一個上課日）第一堂、本週台股 |

特別規則：

- **48 小時內有考試**：任何模式都置頂、紅色強調。
- **期中考週、期末考週**：課表區改成「本週考試」清單。
- **放假日、寒假**：不顯示課表。
- 倒數格式：「今天 19:00」「明天」「D-5」；2 天內紅色、7 天內橘色，標在彩色膠囊裡；行事曆標題開頭是 `留意公告:` 的代表日期未確定，顯示灰色「約」。
- 今天要帶傘時，天氣卡片會多一排未來 12 小時的降雨機率長條圖（50% 以上是實心藍色）。
- EEARS 活動只列跟課表不衝堂、還沒額滿的場次。

**鎖定畫面小工具**（iOS 16 以上）：長按鎖定畫面 → 自訂 → 加入 Scriptable，選這個腳本。
- 長方形：現在最重要的兩件事（例如「C++ 剩 60 分 / 工EC 3014 / 明天 09:10 微積分」）
- 圓形：一個數字（上課中是還有幾分鐘下課；48 小時內有考試就是 D-n；否則是下一堂幾點或氣溫）
- 單行（時間上方）：一句話摘要

**點小工具**會在 Scriptable 裡打開完整儀表板，上方分頁可以切換：

- **倒數**：所有考試／截止（點開看地點與備註）、接下來的美股大事
- **課表**：今天與本週課表、最近的課程異動
- **台股**：完整觀察清單（價格、漲跌%、成交量），紅漲綠跌
- **單車**：即時抓 YouBike 全部設定站點的可借／可還（只在打開時抓，2 分鐘內不重抓）
- **公告**：公告列表，點一下用 Safari 打開原文
- **活動**：14 天內的 EEARS 場次（English Table、Job Talk、English Club），剩幾位、什麼時候開放預約、會不會衝堂，點一下打開預約網站
- **天氣**：逐時氣溫、降雨機率、雨量、UV

最下面還有「預覽大／中／小尺寸小工具」「重新抓所有資料」「立即更新主程式與設定」。

## 要改設定，改哪個檔

全部設定都在 repo 的 `config/` 資料夾，直接在 GitHub 網頁上編輯、commit 就好。小工具大約 6 小時內會抓到新設定（想馬上生效：打開儀表板按「立即更新主程式與設定」）；雲端的 Actions 下一輪就會用新設定。

| 想改什麼 | 檔案 | 說明 |
|---|---|---|
| 課表、教室、節次時間 | `config/courses.json` | `weekday` 1＝週一；`periods` 寫節次（例如 `"234"`，連續節次會自動合成一段）；`buildingToYouBike` 是大樓代號對應的 YouBike 站號 |
| 台股觀察清單、題材分組 | `config/watchlist.json` | `pinned` 是置頂的股票，`themes` 是題材；上市 `tse`、上櫃 `otc` |
| YouBike 站點、我的最愛 | `config/youbike.json` | `stations` 加站號（`no`）和名稱；`"favorite": true` 會排在最前面 |
| 學期、放假日、考試週、寒假 | `config/semester.json` | `noClassDays`、`midtermWeek`、`finalWeek`、`winterBreakStart` |
| 美股大事 | `config/macro-events.json` | `at` 寫台北時間（`+08:00`）；日期未確定的寫 `"confirmed": false`，會顯示「預估」 |
| 公告來源、課程異動監看 | `config/notices.json` | `enabled` 開關每個來源；`courseWatch.courseIds` 是要監看的課號 |
| EEARS 活動預約提醒 | `config/activities.json` | `types` 要提醒哪些活動（`english_table`、`job_talk`、`english_club`、`other`）；`remindBeforeMinutes` 提前幾分鐘；`notifyNewSessions`、`notifyFreedSpots` 開關新場次和空位通知 |
| 天氣地點 | `config/location.json` | Open-Meteo 網址（只由手機呼叫） |

考試和作業倒數**不用改設定**：直接在 Google 日曆（或 iPhone 行事曆）建立事件，標題含「考試、期中、期末、小考、Quiz、Exam、Midterm、Final」會當成考試，含「截止、繳交、報名、deadline、due」會當成截止。

## 常見問題

**小工具沒有更新？**
iOS 會自己決定小工具多久更新一次（通常 15 分鐘到 1 小時，電量低時更久），Scriptable 沒辦法強迫它。點一下小工具打開儀表板會立刻重抓所有資料，小工具下次更新時就會用到。主程式一天檢查一次新版本，急著要新版可以在儀表板最下面按「立即更新主程式與設定」。

**顯示「讀不到行事曆」或收不到帶傘提醒？**
到 iPhone 設定 → Scriptable，確認「行事曆」和「通知」都有打開；然後在 Scriptable 裡手動執行一次腳本。節日、生日類的行事曆會自動略過。

**資料變灰色、後面寫「07:10 的資料」？**
代表那份資料過期了（天氣超過 3 小時、公告超過 90 分鐘）。手機沒網路時會先顯示上次的資料。公告是 GitHub Actions 抓的：到 repo 的 Actions 分頁看 `data` 有沒有正常在跑（紅色叉叉點進去看錯誤）；單一來源失敗時會記在 `notices.json`／`youbike.json` 的 `errors` 欄位，其他來源照常。某個公告來源連續 6 小時抓不到，會推播提醒一次（「公告來源抓不到：電機系所有訊息」）。推播本身送不出去時，那次執行會變紅，GitHub 會寄信給你。

**「公告資料還沒建立」？**
GitHub Actions 還沒成功跑過第一次。確認 Pages 的 Source 是 GitHub Actions，然後到 Actions → `data` → Run workflow。第一次只會建立基準、不推播，避免一次推幾十則；之後的新公告才會推播。

**沒收到推播？**
確認 `NTFY_TOPIC` secret 的值和 ntfy App 訂閱的主題一模一樣，ntfy 的通知權限有打開。可以到 Actions 手動跑 `macro-reminder` 並勾選 DRY_RUN，看 log 會印出推播內容（不會印出主題名稱）。

**公告晚好幾個小時才推？小工具上為什麼沒有 YouBike？**
`data` 設定每 10 分鐘跑一次，但 GitHub 的免費排程是「有空才跑」，實際上一天常常只跑 5～7 次。所以 YouBike 車數已經從小工具拿掉（雲端資料幾乎都是過期的），要看車數請點小工具進 App 的「單車」分頁，那裡抓的是即時資料。公告想要準時的話，可以用免費的 [cron-job.org](https://cron-job.org) 每 10 分鐘叫 GitHub 跑一次（設定一次就好）：
1. GitHub 右上角頭像 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token。Repository access 選 **Only select repositories → nsysu-hud**；Permissions → Repository permissions → **Actions** 設成 **Read and write**，其他都不用。到期日可以選最長，到期前 GitHub 會寄信提醒。複製產生的 token（只會顯示一次，不要貼到任何檔案裡）。
2. 在 cron-job.org 註冊 → Create cronjob：
   - URL：`https://api.github.com/repos/andrewlin9697/nsysu-hud/actions/workflows/data.yml/dispatches`
   - Schedule：每 10 分鐘（可以只選 07–23 點）
   - Advanced → Request method：**POST**；Headers 加三行：`Authorization: Bearer 你的token`、`Accept: application/vnd.github+json`、`X-GitHub-Api-Version: 2022-11-28`
   - Request body：`{"ref":"main","inputs":{"tasks":"auto"}}`
3. 存檔後按「Test run」，回應是 **204** 就成功了；GitHub 的 Actions 分頁會多一筆 `workflow_dispatch` 的 `data`。

`tasks` 一定要填 `auto`：它跟排程一樣只跑到期的工作（公告 25 分鐘一次、課程異動一天一次），不會每 10 分鐘就強制重抓。GitHub 原本的排程照樣保留，兩邊同時觸發也沒關係（會排隊，不會重複推播）。

**排程好像停了？**
公開 repo 60 天沒有活動，GitHub 會停用排程。`keepalive` 每月會檢查，最近 20 天沒有 commit 就自動做一次空 commit。如果還是被停用，到 Actions 分頁找到該 workflow 按「Enable workflow」。

**台股數字怪怪的？**
盤中如果某檔這一段時間還沒成交，會先用買一（或賣一、昨收）當參考價，儀表板會標示「參考價」。非交易時間顯示最近一個交易日的收盤和日期。這裡只呈現資訊，不提供任何買賣建議。

**想手動測試 Actions 而不推播？**
每個 workflow 都可以在 Actions 分頁按 Run workflow，勾選 **DRY_RUN** 就只會在 log 印出結果，不推播也不部署。

## 開發

需要 Node 20 以上，沒有任何外部套件，不用 `npm install`。

```sh
npm test          # 單元測試（node --test，全部用固定的假時間與 fixtures）
npm run build     # 產生 dist/NSYSU-HUD.js（改了 src/ 一定要重新 build 並 commit）
npm run preview   # 用假資料印出每個模式、每個尺寸的版面
npm run preview -- --at 2026-10-28T20:30 --family large   # 指定時間與尺寸
```

```
src/lib/        台北時間、美股大事（小工具和 Actions 共用）
src/widget/     小工具：模式選擇、課表、倒數、天氣、台股、版面、Scriptable 繪製、App 儀表板
src/actions/    GitHub Actions：RPage 公告解析、比對合併、YouBike、課程異動、ntfy
src/dev/        假的 Scriptable／網路／天氣（只給測試和 preview 用，不會打包進小工具）
scripts/        build、preview、Actions 的入口
install/        貼到 Scriptable 的安裝器
config/         所有設定
fixtures/       真實資料樣本（測試用）
```

Scriptable 的 API（`ListWidget`、`Request`、`FileManager`、`CalendarEvent`、`Notification`、`config`、`Script`）都包在 `src/widget/adapter-scriptable.js` 和 `main.js` 後面。測試時用 `src/dev/` 的假實作，並且把打包好的 `dist/NSYSU-HUD.js` 放進沒有 Node API 的沙盒裡實際跑一遍（假物件只接受 Scriptable 真的有的屬性和方法，拼錯就會失敗）。

## 設計決定

規格沒寫到、或需要取捨的地方，這樣決定：

**整體**
- **不加任何相依套件**：HTML 解析用「標籤配對＋正規表示式」（不用 cheerio），先去掉 `<script>`、註解，再依 class 找元素並配對開關標籤取出完整區塊；422 版面只看 `.module-ptlist` 裡的表格，欄位優先用 `data-th`，沒有的話改看表頭或欄位內容（日期格式、有連結的那格、`[單位]`），再不行就找同一區塊裡 403 樣式的列；解析不到時會把網頁標題、長度和找到的區塊數寫進 `errors`，並把列表區塊開頭的 HTML 印在 Actions 的 log（不會進 JSON），方便判斷原因。標籤掃描刻意寬鬆（容許屬性之間沒有空格），列表區塊也會找到下一個 `.module` 為止，避免學校網頁多一個 `</div>` 就整段抓不到。打包用自己寫的小型 CommonJS 打包器，只允許相對路徑的原始碼，Node 模組混進小工具會直接 build 失敗。Actions 因此不用 `npm install`。
- **時間一律用台北時間（固定 +08:00）計算**：台灣沒有日光節約，手機、Actions、測試算出來都一樣。
- `dist/NSYSU-HUD.js` 會 commit 進 repo（安裝器從 main 分支下載它）；`ci` workflow 會檢查它跟 `src/` 一致。

**小工具**
- 主程式和快取放在 Scriptable 的 Library 資料夾，不會出現在腳本列表；build 時把 `config/` 內嵌一份，第一次沒網路也能顯示課表。
- 安裝器用 `new Function` 執行下載的主程式，不依賴 `importModule` 的路徑規則；下載失敗或回應不對（不是 200、內容沒有 `NSYSU-HUD` 標記）都沿用快取。
- 快取時間：設定檔 6 小時、天氣 30 分鐘、台股盤中 2 分鐘／其他時間 30 分鐘、公告 10 分鐘、儀表板的即時 YouBike 2 分鐘。抓不到時用快取並標出資料時間。
- 過期標準：儀表板的 YouBike 30 分鐘（用站點自己的更新時間）、天氣 3 小時、公告 90 分鐘（夜間公告不更新，放寬到 8 小時）、台股盤中 20 分鐘。
- 版面依尺寸估算行數（大尺寸約 16 行）裁切，排不下時越後面的區塊先省略；48 小時內的考試已經置頂時，下面的倒數清單不再重複列出。
- 中尺寸不顯示區塊標題、每個區塊最多 2 行，盡量多放幾種資訊；小尺寸顯示 3 個重點（考試警示、下一堂、最近的倒數或帶傘）；鎖定畫面有自己的三種版面（系統會畫成單色，所以不設顏色和背景）；其他沒見過的尺寸用小尺寸版面，不會壞掉。
- 進度條和降雨長條圖用固定大小的 stack 疊出來，不用 DrawContext 畫圖，這樣會跟著淺色／深色模式切換顏色。
- **每種資料各自隔離**：天氣、台股、公告、YouBike、活動任何一份資料格式壞掉，只有那一區顯示「抓不到」，其他照常；格式不對的欄位（時間、數字）會被略過，不會讓整個小工具出錯。測試裡有一個「整學期壓力測試」：9 月到隔年 3 月每天 22 個時段（含各模式交界）× 6 種尺寸，隨機讓各種資料缺漏或過期，用真的繪製程式跑過約 2.4 萬次，還有一組故意餵壞資料的測試。
- 安裝器下載新版主程式時會先試著編譯一次，下載不完整（語法錯誤）就不會蓋掉手機上能用的那份。

**模式**
- 晚間、深夜**每天**都適用（週日晚上也需要「明天第一堂」）；假日版面只用在週末／放假日的 06:00–18:00。
- 上課日白天：09:10–13:30 有課的日子都算；13:30 之後只要今天還有課（上課中或還沒上）就維持，否則換午後。規格寫到 16:00，這份課表最後一堂剛好 16:00 下課，結果一樣，只是之後有 16:10 以後的課也不會出錯。平日沒課的白天用午後版面。
- 下課空檔時不另外顯示「現在」，直接在「下一堂」標「下課空檔」和還有幾分鐘。小工具上不顯示 YouBike（雲端資料一天只更新約 5 次），只在 App 的「單車」分頁抓即時資料。
- 考試週以 `semester.json` 的日期為準（期中 10/27–10/30），只有考試週當天換成「本週考試」，清單列出那週（週一到週日）行事曆裡的考試；晚間如果明天進入考試週，「明天」卡片也改列考試。
- 寒假或兩週內都沒有課時不顯示下一堂；明天放假會寫出假日名稱。

**倒數**
- 中文關鍵字照規格；英文關鍵字（Quiz、Exam、Midterm、Final、deadline、due）不分大小寫，但要是完整單字（避免 residue 被當成 due）。同時符合時考試優先。
- 48 小時警示只看日期確定的考試，`留意公告:` 的不會變紅。全天事件的結束時間是隔天 00:00（不含），也相容 23:59:59 的寫法。

**天氣**
- 帶傘：現在到 20:00 任一小時降雨機率 ≥ 50% 或雨量 ≥ 0.5 mm；「最可能下雨的時段」是降雨機率最高那小時所在的連續下雨時段。
- 本機帶傘通知排在「下一個 07:30」（凌晨打開時就是當天 07:30），用那天 07:00–20:00 的預報；不下雨就取消；天氣抓不到時不動原本排好的通知。
- 曬太陽：只考慮 09:00–15:00 之間至少 20 分鐘的空檔，下課後先留 10 分鐘走出教室；UV 取整數判斷。有 UV 3–7 的空檔就選其中 UV 最高的 30 分鐘；空檔都 ≥ 8 時選最溫和的那小時，只建議 10 分鐘。

**台股**
- `z` 是 `"-"` 時依序退回買一 → 賣一 → 昨收，儀表板標示「參考價」。題材的「漲最多／跌最多」只有一檔有資料時只顯示一檔。
- 「本週台股」用手機每天累積的收盤價計算（保留 15 個交易日）；剛安裝、還沒有上週資料時顯示最近一次收盤。
- 完全不產生任何建議、訊號或評分，只顯示價格與漲跌。

**GitHub Actions**
- 公告和 YouBike 合併成一個 `data` workflow，每 10 分鐘跑（分鐘數錯開整點）。公告是「距離上次檢查 ≥ 25 分鐘」才跑，而不是看分鐘數，GitHub 排程延遲或跳過時也不會漏掉一輪。
- **每次部署都包含全部資料**：先抓回 Pages 上現有的 `notices.json`、`youbike.json`、`course-state.json`、`activities.json`，這輪沒更新的原樣帶過去；所有會部署的 workflow 共用 `concurrency: pages`。
- 只有 Pages 回 404 才當作第一次；網路錯誤或 `notices.json` 不在但 `youbike.json` 在（代表暫時故障）時，這一輪不部署也不推播，避免狀態被清空後重推一堆舊公告。
- **先部署、成功後才推播**：部署失敗時下一輪會再偵測到同一批新公告，不會重複推播，也不會漏。
- 第一次執行、或之後新啟用的來源，只建立基準不推播；第一次出現但日期超過 14 天的公告（例如被重新置頂的舊文）也靜默記錄。新公告用 `{hostname}:{文章ID}` 比對，不看排序，所以置頂舊文不影響判斷。
- `notices.json` 保留 200 則，目前列表上看得到的優先保留（避免置頂舊文被擠出去後又被當成新的）；同一則出現在兩個來源時只留一則，`source` 是設定檔裡排前面的來源，`sources` 記錄全部。第一次建立基準的公告標 `quiet`，不算在「新公告」裡。
- 課程異動：第一次只建立基準；NSYSUCourseAPI 的 `info.json` 標示資料不完整時，找不到的課先不通知；推播點開是課程大綱。`course-watch` 08:00 沒跑到的話，`data` workflow 在 09:00 之後補跑一次。小工具也會讀 `course-state.json`：教室有異動（且只有一間教室）時直接顯示新教室並標 ⚠︎，不用等你改 config。
- **EEARS 開放預約提醒用 ntfy 的定時送出**：每輪讀 `/api/events` 和 `/api/event-types`，算出每場的開放時間，把未來 70 小時內的提醒交給 ntfy，指定在開放前 5 分鐘送到（ntfy 最多接受 3 天後）。GitHub 排程晚到不影響準時；EEARS 暫時連不到時，已經交出去的提醒照樣會響。每個開放時間有固定的 `sequence_id`（例如 `eears-open-20261028-1200`），內容有變或每 12 小時重送一次都是「取代」原本排好的那則，不會重複；場次被刪掉時會取消還沒送出的提醒。開放前 2 分鐘內不再動它。
- EEARS 第一次執行只建立場次基準（開放提醒照常排程）；之後才通知新場次。「有空位」只看已經開放、還沒截止、上一輪是 0 位的場次，每場只通知一次。跟 `courses.json` 的課重疊的場次全部略過；`activities.json` 只留昨天以後的場次。
- 西灣學院（EMI 中心）的公告頁是表格版的 403 版面（`table.row.listBS` 裡每個 `tr` 一則，日期在標題前），解析器兩種都支援。
- 美股提醒排在台北 **19:45**：GitHub 排程常延遲 10–30 分鐘，這樣大約 20:00 送到，也不會錯過美國夏令時間 20:30 的 CPI。範圍是「現在到明早 06:00（含）」。
- 推播：公告 priority 3（📢）、課程異動 priority 4（⚠️）、美股 priority 3（📈）、開放預約提醒 priority 4（⏰）、新場次 priority 3（🆕）、有空位 priority 4（👀）。一輪最多列 8 則標題，其餘寫「還有 N 則」。
- 公告來源連續失敗滿 6 小時推播一次（`notices.json` 的 `failing` 記每次故障的開始時間，恢復就清掉）；推播送不出去時 `send-pending` 以 1 結束，讓執行變紅。這一輪的內容已經部署成「看過」，不會自動重送。
- 課程異動：教室和時間第一次變成空白時先不通知，下一輪還是空白才算異動（上游偶爾會有一版資料是空的）。
- 中山有些站台不送中繼憑證（2026-11 的電機系網站），workflow 用 `NODE_EXTRA_CA_CERTS` 載入 `config/nsysu-extra-ca.pem` 補上。
- 美股大事清單（`config/macro-events.json`）最後一筆距今不到 30 天時，每週一推播提醒更新。
- keepalive：每月 1 日檢查，最近 20 天沒有 commit 才做空 commit（保證不會超過 60 天沒活動）。
- 所有排程 workflow 都可以手動執行並勾 DRY_RUN；`ci` 只跑測試、不推播也不部署，所以沒有 DRY_RUN。
- Open-Meteo 只由手機呼叫，Actions 完全不碰。

## 不做的事

- 不碰你的電腦、不做任何遠端控制或電腦監控（那是另一個專案）。
- repo 裡沒有任何帳號密碼、cookie、token；不需要登入任何學校系統。ntfy 主題名稱只放在 secret，程式和 log 都不會印出來。
- 台股不提供買賣建議。
